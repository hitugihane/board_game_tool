# board_game_tool

# 一旦アイデア

### ・課題：人生ゲームやモノポリーを行う際、お金やカードの扱いに困る時がある。一番小さな単位のお金の紙が足りなくなりゲーム中にGMが両替して調整したり、パッと見たときにどのプレイヤーがいくら持っているのかが比較しにくいなどモノを扱っている以上さまざまな制約がある。それらをデータとして管理し対面でゲームをやる面白さを残しつつGMでゲームに参加できない人をなくす。

### ・メイン機能：ゲームを作成しお金の入金送金表示が行えるようにする。

### ・コンセプト：玩具箱

### ・環境は最初はローカルのWindowsサーバーを使用し、後でAWS他クラウドに上げたい

### ・JSでスプシがもし操作出来るなら実装出来るかも（備忘録2025/04/07）
